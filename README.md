# Tetris-POO
Projeto desenvolvido em Python para recriar o clássico Tetris utilizando Programação Orientada a Objetos. A aplicação explora classes, objetos, encapsulamento, herança, polimorfismo e composição, organizando a lógica do jogo em peças, tabuleiro e controle de partida, com foco no aprendizado prático de POO.
