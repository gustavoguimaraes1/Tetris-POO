**Tetris em Programação Orientada a Objetos**

Implementação do clássico Tetris utilizando conceitos de Programação Orientada a Objetos (POO).

O Tetris é um jogo eletrônico de quebra-cabeça criado por Alexey Pajitnov em 1984. Sua mecânica consiste em organizar peças geométricas, chamadas tetraminós, que caem continuamente pelo tabuleiro. Linhas horizontais completamente preenchidas são removidas, liberando espaço e aumentando a pontuação.

**Objetivo do projeto**

O projeto tem como objetivo aplicar conceitos de POO na construção de um jogo completo, organizando responsabilidades em diferentes classes e objetos.
